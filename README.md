# #Bash Talk

Offline walkie-talkie i chat za Android. Radi preko Wi-Fija ili hotspota, bez interneta i bez mobilne mreže.

## Funkcije
- 📻 Walkie-talkie: drži dugme ili tipku „glasnoća −”, 🔒 zaključaj za pričanje bez držanja
- 📢 Kanali 1–99, pričaš svima na kanalu ili samo jednoj osobi
- 💬 Chat s potvrdom prijema (✓ / ✓✓), privatne poruke
- 📡 Radar i lista uređaja u blizini: ko je u dometu, ping, jačina veze, obavijest kad neko uđe ili izađe
- 📳 „Zovni” vibrira telefon druge osobe

## Kako spojiti
1. Na jednom telefonu upali hotspot (mobilni podaci ne trebaju)
2. Ostali se spoje na njega preko Wi-Fija
3. Svi otvore #Bash Talk

## Build
GitHub Actions automatski pravi `BashTalk.apk` na svaki push na `main`.
